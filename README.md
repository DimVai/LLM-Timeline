# LLM Timeline

Single-page timeline σε HTML, CSS και JavaScript, χωρίς framework ή build step.

## Προβολή

Άνοιξε το `index.html` μέσω HTTP server (π.χ. Live Server) ή GitHub Pages. Το απευθείας άνοιγμα με `file://` δεν επιτρέπει αξιόπιστα τη φόρτωση του JSON μέσω `fetch`.

## Αρχεία

- `timeline/timeline.json`: κοινή πηγή περιεχομένου. Οι κανόνες σύνταξης βρίσκονται στο `timeline/README.md`.
- `resources/style.css`: dark εμφάνιση, γαλάζιο, έντονο ροζ και ασημί. Οι εποχές ξεχωρίζουν με διαφορετικά backgrounds, διακριτικούς τίτλους και περιγραφές, και κατακόρυφο κενό μεταξύ τους.
- `resources/script.js`: απόδοση δεδομένων, πλοήγηση ανά έτος, σημειώσεις, πηγές και εναλλαγή γλώσσας.
- `index.html`: η μοναδική σελίδα, με ενσωματωμένα header και footer.
- `resources/logo.svg`: λογότυπο και favicon.

Τα έτη παραμένουν μέσα στις εποχές τους, επομένως το 2024 εμφανίζεται σε δύο διαδοχικά τμήματα. Η πλοήγηση προς το 2024 οδηγεί στο πρώτο. Στο desktop εμφανίζονται τρεις στήλες· στο κινητό οι εταιρείες και τα μοντέλα μεταφέρονται κάτω από το αντίστοιχο γεγονός.

## Γλώσσες

Το JSON περιέχει ελληνικά (`el`) και αγγλικά (`en`) στα `title`, `description` και `notes`. Η επιλογή γλώσσας αποθηκεύεται στο `localStorage` με το κλειδί `llm-timeline-lang` και επαναφέρεται στην επόμενη επίσκεψη. Χωρίς έγκυρη αποθηκευμένη επιλογή, η προεπιλογή είναι τα αγγλικά. Η σειρά κουμπιών παραμένει EL → EN. Αν ο browser αποκλείει την αποθήκευση, η εναλλαγή εξακολουθεί να λειτουργεί στην τρέχουσα επίσκεψη. Κάθε νέα εγγραφή χρειάζεται και τις δύο μεταφράσεις· μια γλώσσα ενεργοποιείται όταν είναι πλήρη όλα τα εμφανιζόμενα κείμενά της.

Τα κείμενα της διεπαφής υπάρχουν ήδη και στις δύο γλώσσες μέσα στο `resources/script.js`. Η εναλλαγή αποδίδει ξανά το φορτωμένο περιεχόμενο χωρίς refresh ή νέο αίτημα δικτύου, διατηρώντας τις ανοιχτές σημειώσεις και το σημείο ανάγνωσης στο timeline. Τα ονόματα εταιρειών/προϊόντων και οι πηγές είναι κοινά.

## Φιλοξενία

Όλα τα τοπικά paths είναι σχετικά ώστε η σελίδα να μπορεί να φιλοξενηθεί και σε υποφάκελο GitHub Pages. Δεν απαιτούνται εξωτερικές γραμματοσειρές, βιβλιοθήκες ή υπηρεσίες.
